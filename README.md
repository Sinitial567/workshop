# 工作台

纯前端零依赖的个人效率面板，包含时钟、天气、待办、便签、书签、番茄钟、日历。数据默认保存在浏览器本地（`localStorage`），可选 Supabase 云同步，无需安装、无需构建。

## 本地运行

最简单：双击 `启动工作台.bat`，它会自动启动本地服务器并打开浏览器（<http://localhost:8123>）。用完关闭那个名为「工作台服务器」的小窗口即可停止。

也可以手动启动（二选一）：

```bash
python -m http.server 8123
```

或

```bash
node server.js
```

> 浏览器通知、提示音需要「安全上下文」（`https` 或 `localhost`），因此不建议直接双击 `index.html`（`file://` 协议下受限）。

## 部署到 GitHub Pages

1. 在 GitHub 新建一个**公开仓库**（免费版 Pages 要求公开仓库）。
2. 双击运行 `部署到github.bat`，按提示输入 GitHub 用户名、邮箱和刚建好的仓库地址，脚本会自动完成 `git init`、提交并推送到 `main` 分支。
3. 进入仓库 **Settings → Pages**，将 **Source** 设为 `Deploy from a branch`，分支选 `main`，目录选 `/ (root)`，保存。
4. 稍等片刻，访问 `https://用户名.github.io/仓库名` 即可。

> 如果你更习惯手动操作，也可以依次运行：`git init` → `git remote add origin 你的仓库地址` → `git add -A` → `git commit -m "Initial commit"` → `git branch -M main` → `git push -u origin main`。

## 自定义域名

- 免费托管默认给你一个子域名（如 `用户名.github.io/仓库名`）。
- 想要完全自定义的域名（如 `work.你的域名.com`），需要自己购买域名，然后在 Pages 设置里填入 **Custom domain**，并按提示在域名服务商处添加 `CNAME` 记录。
- 绑定 HTTPS 证书后，浏览器通知等能力即可正常使用。

## 功能

- 时钟问候：数字大时钟、日期星期、按时段问候语。
- 天气：Open-Meteo 免费接口，手动选城市，显示当前天气 + 未来 3 天预报。
- 待办：增删、勾选完成、四档优先级（紫/红/黄/绿，自动排序）、可选截止日期，到期提醒。
- 便签：多张便签、多种颜色、自动保存。
- 书签：分组管理、favicon 图标、新窗口打开。
- 番茄钟：默认 25/5 分钟，可自定义，结束提醒；专注结束自动进入休息。
- 日历：点日期格子为当天添加提醒，与待办截止日期双向同步。
- 设置：深/浅主题、自定义壁纸、改城市、番茄钟时长、提醒开关、JSON 导入导出、云同步。

## 云同步（可选）

数据默认只存在当前浏览器。想在**电脑与手机之间同步**，按下面的步骤操作：

1. 打开工作台，进入 **设置 → 云同步**。
2. 自己设定一个别人猜不到的**同步码**（相当于密码，建议长一点的随机字符串）。
3. 点击启用，首次会把本机数据上传到云端。
4. 在另一台设备上打开同一地址，进入 **设置 → 云同步**，输入**相同的同步码**并启用，即可拉取云端数据；之后两边改动会自动互相同步。

> - 云同步使用 Supabase 免费层，数据以同步码区分，请妥善保管同步码。
> - 同步码不要告诉别人；仓库虽然公开，但云端数据只能通过同步码读取。

## 数据说明

- 未开启云同步时，数据只保存在当前浏览器，不经过任何服务器（天气请求除外）。
- 开启「设置 → 云同步」后，数据会加密传输到 Supabase，可在多设备间同步。
- 不使用云同步时，换浏览器或换设备请用「设置 → 导出」备份，再在新设备「导入」。
- 背景壁纸会被压缩到最长边 1920px 后保存为本地数据。
